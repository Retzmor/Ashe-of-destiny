# Ashes of Destiny

Juego con mecánicas básicas de combate desarrollado en Unity.

## 🎮 Descripción
Ashes of Destiny es un juego donde el jugador controla un personaje con movimiento y combate básico.

## ⚙️ Características
- Sistema de movimiento del personaje
- Sistema básico de combate
- Estructura general del juego

## 🛠️ Tecnologías
- Unity
- C#

## 👨‍💻 Mi rol
Desarrollé toda la programación del juego, incluyendo el sistema de movimiento y combate. También implementé los elementos dentro de Unity y colaboré en el apartado de sonido.
